Football Executive Management — Mobile Prototype
=================================================
Prototype type: standalone HTML mobile UI/gameplay mockup.

How to run:
1. Open index.html in Chrome, Edge, Safari, or Firefox.
2. For a phone preview, open browser developer tools and choose a mobile device size.
3. No server, database, Unity project, or external dependency is required.

Included:
- Club Chairman home dashboard
- Executive decisions
- Club management
- Football World / league view
- Match result presentation
- Football Association President view
- Mobile bottom navigation
- Long-term consequence-style decision feedback

Important:
This is a visual/interaction prototype, NOT production Unity code.
It intentionally avoids direct Starting XI, formation, tactics, substitutions, or player control.
